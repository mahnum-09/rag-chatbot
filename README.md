\# Resume RAG Chatbot



A Retrieval-Augmented Generation (RAG) chatbot for working with resume documents.



\## Technologies

\- Python

\- PostgreSQL

\- Vector search

\- RAG architecture



\## Main Files

\- `app.py` — application interface

\- `chat.py` — chatbot functionality

\- `ingest.py` — document ingestion

\- `search.py` — retrieval and search

\- `check\_chunks.py` — document chunk inspection

\- `test\_connection.py` — database connection testing
